# Chapter 07 학습 기록

## 내가 정한 Breakpoint

- `768px`: 태블릿 및 넓은 화면의 시작점
- `1024px`: 데스크톱 레이아웃의 시작점

## 이 Breakpoint를 선택한 이유

작은 화면에서는 카드의 내용과 버튼이 한 열일 때 가장 읽기 편했다. 768px부터는 카드 두 개를 배치할 공간이 충분했고, 1024px부터는 세 개를 배치해도 각 카드의 제목과 진행 상태가 답답하지 않았다.

## 모바일에서 변경한 레이아웃

모바일을 기본 스타일로 두고 카드 목록을 1열로 구성했다. Header의 제목과 Navigation은 세로로 배치했으며, 입력 요소가 부모 너비를 넘지 않도록 `width`와 `max-width`를 설정했다.

## LLM에게 질문한 내용

Mobile First 방식에서 Grid를 1열, 2열, 3열로 확장하는 방법과 작은 화면에서 가로 스크롤을 방지하는 방법을 질문했다.

## 내가 직접 확인하고 수정한 부분

375px에서는 1열과 세로 Header, 768px에서는 2열과 가로 Header, 1024px 이상에서는 3열이 적용되는지 확인했다. 긴 텍스트가 카드 너비를 밀어내지 않도록 `min-width: 0`과 `overflow-wrap`을 추가했다.
