# Chapter 08 학습 기록

## 이번 장에서 이해한 개념

JavaScript에서 `const`와 `let`으로 값을 저장하고, String·Number·Boolean 자료형을 다루는 방법을 이해했다. 비교·논리 연산자와 조건문으로 값을 판단하고, `for`와 `for...of`를 사용해 여러 값을 반복 처리했다. `console.log()`는 화면 UI가 아니라 개발자 도구의 Console에서 실행 결과를 확인하는 용도라는 점도 배웠다.

## 가장 어려웠던 코드

입력창에서 가져온 값은 숫자를 입력해도 문자열이므로 `Number()`로 변환해야 한다는 점이 어려웠다. 변환 결과가 숫자인지는 `Number.isNaN()`으로 확인했고, 나눗셈에서는 두 번째 숫자가 0인지 별도로 검사했다.

## LLM에게 질문한 내용

`const`와 `let`의 차이, `for`와 `for...of`의 선택 기준, 조건문으로 사칙연산을 처리하는 방법, 계산 결과를 자동으로 테스트하는 방법을 질문했다.

## LLM 답변에서 내가 직접 검증한 내용

브라우저 Console에서 변수 값과 반복문의 출력 순서를 확인했다. 계산기에 정상 숫자, 빈 값, 문자가 포함된 값, 음수, 소수, 0으로 나누기를 각각 입력해 검증했다. `test.js`의 덧셈·뺄셈·곱셈·나눗셈 테스트 결과도 확인할 수 있도록 구성했다.

## 조건문과 반복문의 차이를 내 말로 설명

조건문은 주어진 조건에 따라 실행할 코드를 선택하는 갈림길이다. 반복문은 같은 종류의 작업을 여러 데이터에 차례대로 실행하는 구조다. 회원 과제에서는 반복문으로 회원을 한 명씩 가져오고, 조건문으로 각 회원이 성인인지 미성년인지 판단했다.
